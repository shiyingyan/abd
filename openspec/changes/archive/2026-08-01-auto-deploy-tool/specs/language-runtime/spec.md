## Purpose

管理多种编程语言的运行时环境，支持 Java、Go、Node、Python 的版本指定与一键安装，集成语言自带的多版本管理工具实现项目级环境隔离。

## ADDED Requirements

### Requirement: 语言版本指定

系统 SHALL 允许用户为每个项目指定所需的编程语言及版本。支持的语言包括 Java、Go、Node、Python。

#### Scenario: 配置项目语言版本

- **WHEN** 用户在项目配置中指定语言类型和版本号
- **THEN** 系统保存语言版本配置，构建时使用指定版本的语言环境

### Requirement: 多版本环境隔离

系统 SHALL 使用语言自带的多版本管理工具实现项目级环境隔离。Node 使用 nvm，Python 使用 uv，Java 使用 SDKMAN，Go 使用 gvm 或类似工具。不同项目的语言环境 MUST 互不影响。

#### Scenario: 不同项目使用不同版本

- **WHEN** 项目 A 指定 Node 16 和项目 B 指定 Node 20 同时构建
- **THEN** 系统通过 nvm 为每个构建任务切换到对应的 Node 版本，两个构建互不影响

### Requirement: 版本安装检查

系统 SHALL 在用户指定语言版本后，检查该版本是否已在系统中安装。

#### Scenario: 版本已安装

- **WHEN** 用户指定一个语言版本且该版本已在系统中安装
- **THEN** 系统提示该版本已就绪，可直接用于构建

#### Scenario: 版本未安装

- **WHEN** 用户指定一个语言版本且该版本未在系统中安装
- **THEN** 系统提示该版本未安装，并提供一键安装操作按钮

### Requirement: 一键安装语言版本

系统 SHALL 提供一键安装功能，用户点击安装按钮后，系统通过对应的多版本管理工具自动安装指定版本。

#### Scenario: 成功安装语言版本

- **WHEN** 用户点击一键安装按钮安装指定语言版本
- **THEN** 系统调用对应的多版本管理工具执行安装，安装过程中通过 SSE 实时显示安装日志，安装完成后提示成功

#### Scenario: 安装失败

- **WHEN** 语言版本安装过程中发生错误（网络不通、版本不存在等）
- **THEN** 系统提示安装失败原因，并显示安装日志

### Requirement: 自定义安装目录和运行环境

系统 SHALL 允许用户为每个项目可选地指定编译程序的安装目录和运行环境。如未指定，系统使用多版本管理工具的默认路径。

#### Scenario: 指定自定义安装目录

- **WHEN** 用户在项目配置中指定语言的自定义安装目录
- **THEN** 系统在构建时使用该安装目录下的语言环境

#### Scenario: 未指定安装目录

- **WHEN** 用户未指定自定义安装目录
- **THEN** 系统使用多版本管理工具的默认安装路径
