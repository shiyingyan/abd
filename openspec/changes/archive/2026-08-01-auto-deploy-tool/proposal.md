## Why

在隔离互联网的服务器环境中，无法使用市场上的 CI/CD 工具（如 Jenkins、GitLab CI）。需要一个轻量级的自动部署工具，能在本机或可联网的构建服务器上编译程序，自动将构建产物上传到部署服务器并重启程序。该工具需提供 Web 操作界面，支持多语言项目构建、并发编译、实时日志和构建历史追溯。

## What Changes

- 新建基于 Spring + Spring MVC + Thymeleaf 的 Java Web 应用，前后端不分离架构
- 实现用户注册与登录认证系统，所有操作需登录后访问
  - 密码在服务器端密文保存，使用不可逆哈希算法加盐加密。由 Apache Shiro 框架负责哈希计算和盐管理
  - 前端将密码进行不可逆哈希后以密文形式传输给后端，禁止明文传输；后端再使用不可逆哈希算法加盐后存储
- 提供项目配置管理页面，配置项包括：项目名称、版本号、Git 仓库地址、代码分支、Git 认证信息、构建指令、构建工作目录、部署服务器连接信息、程序在部署服务器部署位置、启动/重启命令等
- 配置存储在后台Mysql数据库，支持通过接口可修改配置，并即时生效无需重启
- 所有认证信息（密码、Token 等）禁止明文存储，通过系统环境变量读取。配置中指定环境变量的key，系统运行时从操作系统环境变量中读取实际值
- 支持多语言编译构建（Java、Go、Node、Python），集成语言多版本管理工具（nvm、uv 等），实现项目级环境隔离。也支持可选项，用户指定编译程序的安装目录和运行环境
- 构建程序支持本机构建和远程构建服务器两种模式；远程构建完成后，后端通过 SCP 将构建产物从构建服务器下载到本地，再上传到部署服务器并自动启动/重启程序
- 通过 SSE 技术实时推送构建日志，每次构建生成的独立的日志文件，日志文件保留 7 天
- 构建记录存储于 Mysql 数据库，保留 3 个月，可查询追溯
- 基于线程池的并发构建，默认20 个并发，并发数可在系统设置中配置
- 每次构建相互独立，配置文件修改不影响正在进行的构建任务

## Capabilities

### New Capabilities

- `user-auth`: 用户注册、登录认证、会话管理，所有系统操作需登录后访问。 使用Apache Shiro框架来开发认证授权功能
- `project-config`: 项目配置管理，Mysql数据库存储、多渠道编辑（页面/HTTP 接口）、格式校验与错误提示、配置修改指南
- `build-management`: 构建流程管理，支持本机和远程构建服务器两种模式、多语言编译、并发线程池、SSE 实时日志推送、独立日志文件（7 天保留）
- `deploy-management`: 部署流程管理，构建产物上传到部署服务器、远程执行启动/重启命令、SSH 连接管理
- `language-runtime`: 多语言运行时管理，支持 Java/Go/Node/Python 版本指定与一键安装，集成 nvm/uv 等多版本工具实现项目环境隔离
- `build-history`: 构建历史记录，Mysql存储，记录项目名/版本/仓库地址/构建时间/用户等信息，3 个月保留期，支持查询追溯
- `system-settings`: 系统设置，包括并发数配置(默认20）、环境变量管理（认证信息读取）、日志保留策略、构建服务器配置

### Modified Capabilities

（无 — 全新项目，无已有 spec）

## Impact

- **新增代码**：整个自动部署工具从零搭建，包含 Spring MVC 控制层、Thymeleaf 视图层、服务层、数据访问层
- **依赖**：Spring Framework、Spring MVC、Thymeleaf、Mysql JDBC 驱动、Apache Shiro（认证授权）、JGit（Git 操作）、Apache MINA SSHD（SSH 连接）、Jackson（JSON 处理）、SLF4J/Logback（日志）
- **外部工具依赖**：Git、各语言 SDK 及版本管理工具（nvm、uv、SDKMAN 等）
- **运行环境**：JDK 8+，需在有网络或无网络的环境中均可运行（构建服务器需有网络访问 Git 仓库）
- **数据存储**：Mysql 数据库,存储构建历史、项目配置、构建日志等信息
