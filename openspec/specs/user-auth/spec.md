## Purpose

提供用户注册、登录认证与会话管理功能，确保所有系统操作均在已认证用户身份下进行，保障系统安全性与操作可追溯性。

## Requirements

### Requirement: 用户注册

系统 SHALL 提供用户注册功能，用户通过用户名和密码进行注册。密码 MUST 以加密形式存储，禁止明文保存。

#### Scenario: 成功注册

- **WHEN** 用户提交有效的用户名和密码进行注册
- **THEN** 系统创建用户账户，密码加密存储，并提示注册成功

#### Scenario: 用户名已存在

- **WHEN** 用户提交已存在的用户名进行注册
- **THEN** 系统拒绝注册并提示用户名已被占用

### Requirement: 用户登录

系统 SHALL 提供登录功能，用户通过用户名和密码登录后获得会话。登录成功后，系统 MUST 记录登录时间和登录用户信息。

#### Scenario: 成功登录

- **WHEN** 用户提交正确的用户名和密码
- **THEN** 系统创建会话，跳转到主页面，记录登录信息

#### Scenario: 凭证错误

- **WHEN** 用户提交错误的用户名或密码
- **THEN** 系统拒绝登录并提示用户名或密码错误

### Requirement: 访问控制

系统 SHALL 对所有功能页面和接口实施访问控制，未登录用户 MUST 被重定向到登录页面。

#### Scenario: 未登录访问受保护资源

- **WHEN** 未登录用户访问任意功能页面或 API 接口
- **THEN** 系统重定向到登录页面（页面请求）或返回 401 未授权（API 请求）

#### Scenario: 已登录访问受保护资源

- **WHEN** 已登录用户访问功能页面或 API 接口
- **THEN** 系统正常响应请求

### Requirement: 会话管理

系统 SHALL 维护用户会话，支持会话超时自动过期和用户主动退出登录。

#### Scenario: 会话超时

- **WHEN** 用户会话超过配置的超时时间未活动
- **THEN** 系统自动终止会话，用户再次操作时被重定向到登录页面

#### Scenario: 主动退出

- **WHEN** 用户点击退出登录
- **THEN** 系统终止当前会话，跳转到登录页面

### Requirement: 密码安全

系统 MUST 对用户密码进行加密存储，禁止明文保存密码。系统 SHALL 使用不可逆哈希算法对密码加盐加密，由 Apache Shiro 框架负责哈希计算和盐管理。前端 MUST 将密码进行不可逆哈希后以密文形式传输给后端，禁止明文传输。

#### Scenario: 密码加密存储

- **WHEN** 用户注册或修改密码
- **THEN** 前端将密码不可逆哈希后以密文传输给后端，后端通过 Shiro 生成随机盐，使用不可逆哈希算法对密文加盐后计算最终哈希值并存储，数据库中不存在明文密码

#### Scenario: 密码登录验证

- **WHEN** 用户登录时提交密码
- **THEN** 前端将密码不可逆哈希后以密文传输给后端，后端通过 Shiro 使用存储的盐对密文进行哈希计算并与存储的哈希值比对，一致则验证通过
