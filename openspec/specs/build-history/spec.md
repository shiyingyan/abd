## Purpose

记录和查询所有构建历史，使用 MySQL 数据库存储构建记录，支持按条件查询追溯，记录保留最长 3 个月后自动清理。

## Requirements

### Requirement: 构建记录存储

系统 SHALL 将每次构建的记录保存到 MySQL 数据库中。记录信息 MUST 包括：项目名称、程序包名、版本号、Git 仓库地址、构建时间、当前登录用户、构建状态（成功/失败）、构建模式、构建日志文件路径。

#### Scenario: 构建完成后保存记录

- **WHEN** 一次构建任务完成（无论成功或失败）
- **THEN** 系统将该次构建的完整信息保存到 MySQL 数据库中

### Requirement: 构建记录查询

系统 SHALL 提供构建历史查询页面，支持按项目名称、版本号、构建时间范围、构建状态、用户等条件查询。

#### Scenario: 按条件查询构建历史

- **WHEN** 用户在构建历史页面输入查询条件并提交
- **THEN** 系统从 MySQL 数据库中检索匹配的构建记录并分页展示

#### Scenario: 查看构建详情

- **WHEN** 用户点击某条构建记录
- **THEN** 系统展示该次构建的详细信息，包括构建配置、构建状态、构建日志

### Requirement: 记录自动清理

系统 SHALL 自动清理超过 3 个月的构建记录。清理操作 MUST 同时删除数据库记录和对应的日志文件。

#### Scenario: 自动清理过期记录

- **WHEN** 构建记录超过 3 个月保留期
- **THEN** 系统自动删除数据库中的过期记录及对应的日志文件

### Requirement: 构建日志关联

系统 SHALL 在构建历史记录中关联对应的构建日志文件，用户可从历史记录直接查看完整构建日志。

#### Scenario: 从历史记录查看日志

- **WHEN** 用户在构建历史详情中点击查看日志
- **THEN** 系统展示该次构建的完整日志文件内容
