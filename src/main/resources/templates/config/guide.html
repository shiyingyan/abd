配置修改指南

字段说明
字段必填说明
项目名称是唯一标识项目的名称
版本号是当前部署的版本号
Git 仓库地址是代码仓库的 HTTPS 或 SSH 地址
代码分支否默认 main
Git 认证环境变量名否存放 Git Token 的环境变量名，系统运行时从环境变量读取实际值
构建指令是编译项目的命令，如 mvn clean package
构建工作目录否执行构建指令的工作目录
语言类型否JAVA/GO/NODE/PYTHON，用于版本管理
语言版本否对应语言的版本号
自定义安装目录否语言环境的自定义安装路径，留空使用默认
部署服务器地址是目标服务器 IP 或域名
SSH 端口否默认 22
用户名否SSH 登录用户名
认证环境变量名否存放 SSH 密码/密钥的环境变量名
部署目标路径是构建产物在服务器上的部署位置
启动命令否首次部署时的启动命令
重启命令否更新部署时的重启命令
注意事项
  • 所有认证信息（密码、Token）禁止明文存储，通过环境变量引用
  • 配置修改后即时生效，无需重启系统
  • 正在进行的构建任务使用修改前的配置，不受影响
  • 字段校验失败时拒绝保存，需修正后重新提交
  • 也可通过 HTTP 接口修改配置: POST /api/configs (JSON)
